One per system: how it is built to deliver its promises, kept true to the
design as built. The label says whether a session may rely on a doc or must
re-check it: `verified <date>`, `unverified`, or `historical`. A dated
amendment, written in the same commit as the code it describes, is a check
against the code and moves the label to its date (the maintainer,
2026-10-28).
